# PDF Thumbnail Telegram Bot

بوت Telegram عام:
1. المستخدم يرسل PDF.
2. يرسل صورة.
3. البوت يعيد نفس الـPDF مع Thumbnail خارجي فقط.

الصورة لا تضاف إلى محتوى الـPDF.

## Render
- ارفع المشروع إلى GitHub.
- أنشئ Worker على Render.
- Build: `pip install -r requirements.txt`
- Start: `python bot.py`
- أضف Environment Variable:
  - Key: `BOT_TOKEN`
  - Value: توكن BotFather
